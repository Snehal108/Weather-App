## 🌦️ Weather Website
A responsive, dynamic weather Website that fetches real-time weather using the OpenWeatherMap API.
Includes geolocation support, speech synthesis, dark mode, and a weather-based background with personalized messages.

## 🛠️ Features
🔍 Search weather by city name
📍 Get weather using your location
🌄 Dynamic background changes with weather
🗣️ Voice assistant reads out care messages
🌓 Dark mode toggle
🕐 Real-time, date and time display
💬 Care suggestions based on temperature and weather (e.g., carry umbrella, drink water)
📱 Mobile responsive with TailwindCSS

## 🧠 Tech Stack
HTML
Tailwind CSS
JavaScript 
OpenWeatherMap API
Web Speech API (for text-to-speech)
Geolocation API
